## task

[Manage tasks](/reference/task). Operations are grouped by baseline access.

| Baseline access | Operations |
| --- | --- |
| `crm:read` | `list`, `prepareDelivery`, `reviewDelivery`, `applyApproval`, `create`, `batch`, `update`, `cancel`, `assignmentOptions`, `reassign`, `dealList`, `creationOptions`, `createAssigned`, `complete`, `delete`, `start`, `updateDueDate`, `attach-document` |
| `email:read` | `snooze`, `unsnooze` |

## task-views-read

[Read Task Views](/reference/task-views). Requires account enablement. Operations are grouped by baseline access.

| Baseline access | Operations |
| --- | --- |
| `crm:read` | `slack-link`, `producers`, `history-read`, `list`, `list-archived`, `read`, `items`, `candidates`, `unmatched`, `resources`, `strategy-status`, `draft-outcomes`, `importance-preview`, `memberships`, `open` |

## task-views-write

[Configure and organize Task Views](/reference/task-views). Requires account enablement. Operations are grouped by baseline access.

| Baseline access | Operations |
| --- | --- |
| `playbook:write` | `create`, `initialize`, `invoke-action`, `restore-history`, `configure`, `saved-policy`, `archive`, `restore`, `associate`, `patch-values`, `upsert-context`, `manual`, `organize`, `place` |

## sequence

[Author sequence drafts](/reference/sequence). Operations are grouped by baseline access.

| Baseline access | Operations |
| --- | --- |
| `crm:read` | `list`, `get`, `attachment-context` |
| `sequences:write` or `sequence:write` | `create` |
| `sequence:write` | `update`, `attach-task` |

For a specific request, check [permissions](/getting-started/permissions) and the schema returned by your connection. Account, resource and action checks still apply.
