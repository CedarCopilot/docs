---
title: "Build tables & boards"
description: "Organize structured work in rows or move cards through a workflow."
---

For an account research list, start with a [table](/documents/tables). Define one row per account, bind CRM columns where supported, and give each research result a source. Use the [tables skill](/skills/tables) before editing existing rows so you preserve their identities.

For a review queue with a visible stage for each item, use a [board](/agent-platform/boards). Set the fields and grouping, then create or move cards as work progresses. Check the runtime before choosing the format: the [table tool](/reference/table) is available through external MCP, while [board operations](/reference/board) run inside Cedar.
