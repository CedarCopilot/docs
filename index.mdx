Cedar's Model Context Protocol server connects your AI client to GTM evidence and actions: LinkedIn, Slack, email, CRM records, signals, meetings, calendars, tasks, knowledge, documents, tables, pipeline analytics, and configuration. Its skills also guide collateral creation, sales coaching, deal analysis, and persistent agent workflows.

## What you can build

| Workflow | Cedar capabilities |
| --- | --- |
| Find relevant people and prepare outreach | LinkedIn search and engagement → prospect screening → CRM context → drafts or authorized scheduled sends |
| Watch a customer Slack channel | Channel source → filtered playbook trigger → evidence check → notification |
| Act on a website visit | Visitor provider or form → Cedar HTTP input/playbook → qualification → reviewable follow-up |
| Monitor buyers and accounts | Person/company watchers → signal history → evidence-backed review → tasks or drafts |
| Keep a pipeline current | Email, Slack, meetings and LinkedIn context → CRM fields → analytics |
| Give agents a persistent workspace | Lists, row-addressed tables, flowcharts, reports, tasks and configured playbooks |
| Turn recommendations into owned work | Task inventory → eligible assignee → preparation or approval → completion and verified result |
| Build buyer-facing materials | Deal evidence + knowledge base + templates → deck, one-pager, business case or action plan |
| Coach reps and explain pipeline outcomes | Qualification frameworks + field history + taxonomy evidence + server-computed metrics |
| Roll out team configuration | Effective playbooks + field rollups + authorized field/mapping propagation |
| Manage operating workflows | Assigned tasks + saved views + inboxes + notifications + spending controls |

## How to use these docs

Start with **Overview**, then choose **Agent platform**, **Channels**, **Enrichment**, **Pipeline intelligence** or **Brain**. Every family opens with an overview before its detailed capabilities, guides and tool contracts. Shared channel tools live under Channels; data-layer tools live under Brain; user tasks, specialized outputs, agent templates and skills live inside Agent platform. **Overview** contains connection guides, the full reference, workspace preferences and administration. The tool reference preserves the complete schema for each family; consult it for exact field names, enums, limits, and response branches. JSON snippets in guides are **tool arguments** unless explicitly labeled JSON-RPC or HTTP. Replace example identifiers with values returned by your account.

This documentation was audited against repository source on **October 29, 2026**. A deployed server may differ; its `tools/list` response, `load-skill` instructions, and runtime capability discovery take precedence. [Capability boundaries](/getting-started/capability-boundaries) identify app-only, gated, and separate-API features.
