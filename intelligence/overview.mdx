Pipeline intelligence is Cedar's analytical layer for revenue work. It combines server-computed metrics, historical deal evidence, configurable commercial signals and guided analysis. Brain supplies the underlying data; the agent platform can turn an analysis into a recurring workflow.

## Questions you can answer

| Question | Capability |
| --- | --- |
| Which open deals are quiet or aging? | `quiet_gap`, `deals_dropped`, `open_deal_age`, `hygiene`, and current deal evidence |
| How quickly do reps respond and follow up? | `response_time`, `followup_time`, `post_meeting_time`, `reply_rate` |
| Where do deals progress or stall? | `time_between_stages`, `stage_funnel`, `win_rate`, `aop_conversion` |
| What is the pipeline value or revenue at risk? | Stored pipeline metrics, stalled-deal revenue, and separately verified live CRM amounts |
| Which objections or competitors recur? | Field discovery, extracted-evidence search, original source reads and cohort analysis |
| Which accounts deserve a commercial review? | Revival, upsell, expansion, churn and follow-up findings, with current-state verification |
| What changed in a buyer or account? | Entity-change rules, Fiber trackers, saved discovery searches and native engagement evidence |

## Work from a defined sample

Choose the deals, reps, reporting period and outcome definition first. Use `conversation-analytics describe-metrics` to discover valid metric/grouping combinations. Use the Brain evidence tools for drill-down and guarded SQL when a supported metric does not answer the question. Preserve missing values and currency boundaries instead of manufacturing a total.

Make the backing visible: retain `n`, sample IDs, grouping, units and the reporting window. Verified live CRM amounts add provider provenance and the actual deal inventory. The [visibility and statistical backing guide](/intelligence/statistical-backing) explains these fields, per-deal normalization, coverage and the distinction between descriptive evidence and an explicitly performed statistical test.

The gated `analysis-decomposition` and `deal-intelligence-analysis` skills guide multi-step analytical work. Coaching and collateral skills provide additional operating instructions; they do not create new data access or sending permissions.
