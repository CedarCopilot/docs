## Capabilities

[Staff administration overview](/operations/support-and-staff) · [Complete capabilities](/capabilities/staff).

<Accordion title="Full tool behavior and constraints">

Cedar staff only. organization-accounts paginates member organizations; provision-organization-accounts requires organizationIds/reviewReference and creates no funds or grants. organization-monthly-limits previews or applies (apply:true) $50/$80/$100 then each $100 notifications, preserving customer limits. Preview canonical Stripe subscriptions before verify-import with reviewed snapshotHash/ownershipReference. Immutable offers, catalog and prospective allowances require approved terms; never invent prices or modify existing Stripe plans/quantities. payment-events reads outcomes; retry-payment requires reviewReference/idempotencyKey and revalidates evidence. postpaid reads organization configuration. configure-postpaid requires postpaid:&#123;accountId,enabled,expectedVersion,subscriptionId?,rolloutReference&#125;; only the real staff operator may perform this rollout. It records staff authority and customerConsentAsserted:false, never customer opt-in or impersonation. Existing payer/eligibility checks remain. process-postpaid processes frozen usage or a known batchId; no caller-supplied amounts. correct-usage requires a reviewed correction.

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `inventory` | Inspect staff-only billing inventory. | `billing:read` |
| `preview-import` | Preview canonical subscription evidence before a reviewed historical import. | `billing:read` |
| `verify-import` | Verify an import using the reviewed snapshot and ownership reference. | `billing:write` |
| `reconcile-subscription` | Reconcile supported subscription accounting state from verified evidence. | `billing:write` |
| `save-offer` | Save an approved immutable commercial offer without inventing or changing existing plan terms. | `billing:write` |
| `save-catalog` | Save approved billing catalog configuration. | `billing:write` |
| `save-allowance` | Save an approved prospective allowance. | `billing:write` |
| `payment-events` | Inspect payment-processing outcomes. | `billing:read` |
| `retry-payment` | Retry an eligible payment-processing operation with reviewed evidence and an idempotency key. | `billing:write` |
| `process-postpaid` | Process frozen usage or an existing batch; callers cannot supply arbitrary amounts. | `billing:write` |
| `postpaid` | Inspect organization postpaid configuration with staff authority. | `billing:read` |
| `configure-postpaid` | Apply a reviewed staff postpaid rollout without representing it as customer opt-in. | `billing:write` |
| `correct-usage` | Apply a reviewed usage correction through the controlled correction path. | `billing:write` |
| `organization-monthly-limits` | Preview or apply supported notification thresholds while preserving customer limits. | `billing:write` |
| `organization-accounts` | Page through member organizations and their billing-account state. | `billing:read` |
| `provision-organization-accounts` | Provision reviewed organization accounts without creating funds or spending grants. | `billing:write` |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.
