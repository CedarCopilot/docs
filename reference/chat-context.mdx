## Capabilities

[Chat context and history overview](/agent-platform/chat) · [Complete capabilities](/capabilities/chat).

<Accordion title="Full tool behavior and constraints">

Manage this chat thread's context set — the items (conversations, email/slack threads, files, deals) the thread is working with, and its primary conversation.  ACTIONS: - manage: attach/detach items and repoint the primary in one call. Pass manage: &#123; add?: &#91;&#123;kind,id,label?&#125;&#93;, remove?: &#91;&#123;kind,id&#125;&#93;, setPrimary?: &#123;id,name?&#125;, reasoning &#125;. Adding is an upsert by (kind,id). Call this when the user redirects to a different conversation, when you attach a newly-created file, or when you resolve an entity by a KNOWN id. - resolve: turn a name the user said ("the Numeral deal", "pull up Acme") into the thread's PRIMARY conversation in one step — searches by name, picks the best match, attaches it. Pass resolve: &#123; query, reasoning &#125;. Only kind="conversation" is supported; for a known id of another kind, use action: "manage".  Each action takes its params in a same-named object — omit every params object except the one matching your chosen action.

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `manage` | Attach/detach working-context items and optionally change the primary conversation. | `in-app` — unavailable externally |
| `resolve` | Resolve a conversation name into the chat's primary conversation and attach it. | `in-app` — unavailable externally |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.
