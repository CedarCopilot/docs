This index is generated from the same schemas as the reference, including nested change unions. It contains **524 selector choices** across **52 tools**. Choices include operation modes and document types; they are not a count of independent APIs. Tools without a selector appear as single-call capabilities.

Staff, feature-gated, and app-only entries are labeled. An action requiring `in-app` remains unavailable externally even when its parent family is listed. Additional path, role, and provider checks still apply.
