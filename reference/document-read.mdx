## Capabilities

[Documents overview](/modules/documents-tables) · [Complete capabilities](/capabilities/documents).

<Accordion title="Full tool behavior and constraints">

Cedar Docs — agent-curated persistent memory. Read-only. ACTIONS: (1) read — fetch a specific doc by virtual path, full markdown content. (2) list — what docs exist under a path prefix (metadata only, no content). Call this at the start of complex tasks before deciding what to read. (3) search — regex search across docs, returns excerpts with context lines, not full content. Use for a specific fact; use read for full context. Each action takes its params in a same-named object (action: "read" with read: &#123;path&#125;) — omit every params object except the one for your action. Personal chat instructions: #chat-agent → user/playbooks/CHAT_AGENT.md. Path shortcuts (#kb, #wiki, #playbook, #here, ...) and content shortcuts (#sections, #outline, #section/&#123;Name&#125;, #lines/&#123;a&#125;-&#123;b&#125;) are NOT listed here — you MUST call load-skill("documents") for the full reference before constructing any non-trivial path or reading a doc you haven't sized up yet. Never modifies anything — use document-write to create, edit, delete, restore, move, or share a doc.

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `read` | Read authorized document content, including supported windows or returned buffer handles. | `docs:read` |
| `list` | Discover files and folders in the authorized virtual document workspace. | `docs:read` |
| `search` | Find documents or matching passages using the supported search filters. | `docs:read` |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.

### read

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `path` | string | Yes | Exact virtual path of the document to read. Supports both path shortcuts and content shortcuts — see this tool's description for the full reference.  |
| `targetUserId` | string | No | Org owner/admin only: the org member whose documents to operate on instead of your own (e.g. to read or edit their playbook). Omit to operate on your own documents.  |
| `ownerUserId` | string | No | Read the copy of this PATH owned by this person (list-documents rows carry ownerUserId). Path reads only, not document ids. Only among documents you can already read.  |
| `includeHistory` | boolean | No | Also return the last few edit sessions (when, who, origin, word change; no content). Use to see whether and by whom a doc such as an agent spec was recently changed.  |
