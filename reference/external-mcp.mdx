Generated from Cedar's actual registration and Zod schemas. Your connection's `tools/list` is authoritative for availability. See [calling tools](/getting-started/calling-tools) and [permissions](/getting-started/permissions).

<Warning>This tool is registered only inside Cedar. External MCP clients cannot call it. Its contract is included to document the complete module boundary.</Warning>

## Capabilities

[Connected systems overview](/integrations/external-systems) · [Complete capabilities](/capabilities/systems).

<Accordion title="Full tool behavior and constraints">

Call a tool on one of the user's connected external MCP servers (Notion, Linear, custom integrations, …). Load the `external-systems` skill first — it lists which connections exist and which tools each exposes. Actions: "call".

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `call` | Call an authorized tool on a connected MCP server discovered through external-system context. | `in-app` — unavailable externally |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.

## Parameters

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |

| `call` | object | No |   |

### call

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `connectionName` | string | Yes | The name of the MCP connection as shown in the loaded skill instructions  |
| `toolName` | string | Yes | The MCP tool to call as listed under the connection in the loaded skill instructions  |
| `arguments` | object | Yes | Arguments to pass to the MCP tool — check the tool description for required fields  |
