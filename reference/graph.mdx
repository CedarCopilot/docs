---
title: "graph"
description: "Import and update a deal org chart."
---

Use the graph family to read or update an authorized deal's org chart. External access requires an enabled account, the deal's conversation ID and the exact path `conversation/{id}/org-chart`. For creation, select the `org-chart` template. Use `read` to inspect the chart and its people before editing. Select a known node to change its fields, or connect two known nodes to record a relationship.

Graph writes return lint findings. Re-read the chart after an edit and check the node or relationship you intended to change. Viewer permissions restrict writes even when the family is discoverable. Other graph operations available inside Cedar are outside this external contract.
