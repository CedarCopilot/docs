## Capabilities

[Skill loading overview](/reference/skills) · [Complete capabilities](/capabilities/skills).

<Accordion title="Full tool behavior and constraints">

Load a Cedar deal-intelligence "brain" skill's full instructions by name. These are the reasoning/analysis skills for deep pipeline questions — how deals are won/lost, cross-deal patterns, rep coaching from real calls, objection/competitor analysis. When your task is such an analysis, you MUST call this tool for the matching skill before proceeding. The one-liners below are only for picking WHICH skill applies — they do not replace loading it. If your client saves this tool's response to a file instead of showing it inline, you MUST read that file in full before acting. Call with no `name` for the full catalog. Available brain skills: &lt;available_skills&gt; - deal-intelligence-analysis: Analyze a customer's deals to uncover non-o… &#91;+8 resources&#93; - analysis-decomposition: Turn a high-level sales-coaching / diagnost… &#91;+4 resources&#93; &lt;/available_skills&gt;  When your task matches a skill, use the load-skill tool to read its full instructions before proceeding.

</Accordion>

Required baseline scope: `brain:read`. Additional role and target checks apply.

## Parameters

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `name` | string | No | Brain skill name — see the tool description for available names. Omit to get the full catalog with complete descriptions.  |
| `resource` | string | No | Optional sub-resource within the skill, if it has one.  |
| `user_request_summary` | string | Yes | One sentence, in your own words: what the user actually asked you to do in this turn. Used only for Cedar's observability — it does not change what this tool does.  |
| `is_new_request` | boolean | Yes | true on the FIRST Cedar tool call of a NEW user request; false when this call continues the same request you are already working on. Groups related calls into one activity thread.  |
