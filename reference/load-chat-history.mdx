## Capabilities

[Chat context and history overview](/agent-platform/chat) · [Complete capabilities](/capabilities/chat).

<Accordion title="Full tool behavior and constraints">

Load a past chat thread's own message history — use after search-chat-history finds the thread you want, when the user wants to pick that conversation back up rather than just being told it exists.  Pass &#123; threadId, limit? &#125;. Returns the thread's messages (including prior tool calls/results) as a formatted transcript for you to read and continue from. This does NOT switch the user's screen to that thread — it only gives you the content for this turn, so tell the user what you found/did if it matters that they see it.

</Accordion>

Required baseline scope: `in-app`. Additional role and target checks apply.

## Parameters

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `threadId` | string | Yes | The id of the past chat thread to load, from a search-chat-history result.  |
| `limit` | integer | No | Max messages to load, most-recent-first cutoff. Default 60. minimum: 1; maximum: 100 |
