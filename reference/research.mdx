<Accordion title="Tool behavior and constraints">

For a requested basic Crustdata lookup, use identify-company with identifyCompany:&#123;domain,idempotencyKey?&#125;. Ranked matches include name, domain, LinkedIn page, logo, industries, type and founding year. Identify costs zero credits and supplies automatic conversation metadata. Use enrich-company for rich profiles by domain or locally resolvable companyName. enrich-person accepts email or linkedinUrl. For Crustdata, resolve a verified LinkedIn URL from saved contacts or name/employer web research and include email when known. Never guess identities or ask the user to find the URL. Select email-only alternate providers explicitly. capabilities lists supported fields. choose-enrichment takes chooseEnrichment:&#123;description,question,knownFields?,provider?&#125; and selects operations without a supplier lookup. Save selections in authorized agent config files and revalidate before reuse. Crustdata is the rich-research default and the meeting-prep provider. Honor provider preferences. Watchers use signals-write. Rich profiles are metered, including background work. Use grants, compatible caches and receipts for actual Cedar charges. Before a workflow exceeds $50 or 100 attempted records across batches, retries and subagents, stop on workflow_confirmation_required for approval in Cedar. Retry an approved pre-dispatch denial with a fresh key in the same workflow. Never split work to evade limits. Confirm the whole count for Crustdata tasks over 50 people. chat-usage takes no parameters and reads counts, cache hits, pending outcomes and charges for this chat and its delegates for free. Pass only the matching action object. enrichPerson.write_to_file buffers profiles.

</Accordion>

## Enrichment operations and field coverage

The discovery catalog exposes **11 enrichment operations** across **5 providers**. These operation IDs are catalog entries selected through `choose-enrichment`, not additional top-level MCP tools. Catalog presence does not check credentials or authorize paid execution. For manual person/company enrichment, explicitly select **Fiber**; the shipped default is recorded separately in the tool contract. There is no automatic provider fallback.

## Basic company identity and usage

`identify-company` uses `identifyCompany.domain` (trimmed, 1–253 characters) and optional `idempotencyKey` (1–200 characters). It returns ranked basic matches under `identifyCompany.results`, with company ID, name, match score and available domain, LinkedIn page, logo, industries, company type and founding year. It costs zero credits and is distinct from paid rich enrichment. Honor an explicitly chosen alternate provider.

`chat-usage` takes no nested parameters and is **Cedar app only**. `chatUsage` reports counts, cache hits, pending outcomes and charges for the current chat and delegates, plus research credit-report coverage. Inspect `truncated`, `notes`, pending counts and reconciliation indicators before calling the totals final.
