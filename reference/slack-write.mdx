Pull a specific Slack thread from the connected user's LIVE Slack into an existing Cedar deal. ACTION: (1) sync-thread — given an explicit channelId + threadTs (from slack-read's search-live) and a conversationId, fetch the thread and attach it to that deal's timeline, where it's stored. Ingests + attaches only — it does not search. Params go under syncThread: &#123;...&#125;.

### syncThread

Pull a specific Slack thread from the connected user's LIVE Slack into an existing deal, where it's stored and attached to the conversation timeline. Get channelId/threadTs from slack-read's search-live first. This INGESTS + ATTACHES only — it does not search.

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `conversationId` | string | Yes | The EXISTING Cedar deal to attach the Slack thread to. format: "uuid" |
| `channelId` | string | Yes | Slack channel id (e.g. "C0123ABC") — from a search-live match. minLength: 1 |
| `threadTs` | string | No | Thread root ts to pull (e.g. "1700000000.123456"). Omit to pull the channel's recent messages.  |
