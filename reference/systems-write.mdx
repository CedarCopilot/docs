## Capabilities

[Connected systems overview](/integrations/external-systems) · [Complete capabilities](/capabilities/systems).

<Accordion title="Full tool behavior and constraints">

Connect Cedar to an external system, or change how it is reached. MCP SERVERS — connect Cedar to one by URL. Storing a named CREDENTIAL for a system Cedar has no built-in integration for (Xero, a Microsoft Graph tenant identity, an internal API) is in-app/chat-only and not offered here. Use read-settings sections:&#91;"connections"&#93; first to see what already exists. Change types: (1) manage_mcp_connection: create/delete an MCP server by URL — public hosts only. A server that needs a static Authorization header must be added from the in-app chat, not here. (2) update_mcp_connection_settings: change an existing server's agent instructions or its background-agent access. SCOPE: "user" is that one person; "org" applies to every member of their organization and requires the caller to be an org admin. A user-scoped entry always shadows an org one of the same name.

</Accordion>

Required baseline scope: `playbook:write`. Additional role and target checks apply.

## Supported options and filters

Every finite input choice is listed here, including array values and nested variants. Free-text filters, dates, numeric ranges and runtime validation are covered in the [parameter tables](/reference/systems-write#parameters). Options apply to their named operation or branch.

| Input | Choices | Variant / meaning |
| --- | --- | --- |
| `change.type` | `manage_mcp_connection` | type=manage_mcp_connection |
| `change.op` | `create`, `delete` | type=manage_mcp_connection — create/delete an MCP server connection. |
| `change.scope` | `user`, `org` | type=manage_mcp_connection — Defaults "user". "org" shares the server with every member of the organization (org admins only); a member's own connection of the same name still wins. |
| `change.type` | `update_mcp_connection_settings` | type=update_mcp_connection_settings |

## Parameters

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `description` | string | Yes | ONE plain-English sentence describing the change — the only thing the user will see. Name the system and what is happening to it. NEVER quote a credential value here; this string is shown to the user and recorded verbatim.  |
| `change` | object or object | Yes |   |
| `targetUserId` | string | No | Store the entry for ANOTHER user in your organization instead of yourself. Omit for your own, which is almost always what you want.  |
| `user_request_summary` | string | Yes | One sentence, in your own words: what the user actually asked you to do in this turn. Used only for Cedar's observability — it does not change what this tool does.  |
| `is_new_request` | boolean | Yes | true on the FIRST Cedar tool call of a NEW user request; false when this call continues the same request you are already working on. Groups related calls into one activity thread.  |

### change — type: manage_mcp_connection

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `type` | "manage_mcp_connection" | Yes |   |
| `op` | "create" · "delete" | Yes | create/delete an MCP server connection.  |
| `connectionId` | string | No | Required for delete. From read-settings sections:&#91;"connections"&#93;.  |
| `name` | string | No | Required for create; the label the agent addresses this server by, e.g. "Mintlify Docs". minLength: 1; maxLength: 128 |
| `serverUrl` | string | No | Required for create; the MCP server URL. Public hosts only - loopback and private ranges are refused. format: "uri" |
| `instructions` | string | No | Hint for the agent on when to use this source. maxLength: 4000 |
| `scope` | "user" · "org" | No | Defaults "user". "org" shares the server with every member of the organization (org admins only); a member's own connection of the same name still wins.  |

### change — type: update_mcp_connection_settings

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `type` | "update_mcp_connection_settings" | Yes |   |
| `connectionId` | string | Yes | From read-settings sections:&#91;"connections"&#93;.  |
| `instructions` | string | No | Replaces the connection's agent instructions. maxLength: 4000 |
| `availableToBackgroundAgents` | boolean | No | Whether cron/event/automation runs may call this server.  |
