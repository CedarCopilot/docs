## Prepared delivery and task outputs

Use `prepareDelivery` to save the personalized sequence plan on a task for human approval. Read `reviewDelivery` with the task ID to see progress. For a saved sequence draft, obtain the attachment versions from the [sequence tool](/reference/sequence). To attach an existing readable document to your own open task, use `attach-document` with its document ID and the current task revision and assignment version. A successful attachment leaves the task open.

Use `batch` for event-bound creates, edits or references that belong in one Task View delivery group. Check the returned item results. Neither preparing the plan nor grouping tasks sends a message.
