## Capabilities

[Saved views overview](/workspace/saved-views) · [Complete capabilities](/capabilities/views).

<Accordion title="Full tool behavior and constraints">

Discover the user's saved/pinned CRM views. ACTIONS: (1) list-canvases — use for named home/pipeline/saved views. Every returned canvas is already pinned (pinnedToHomeView:true). Owned canvases include native viewConfig to preserve when editing. Returns each pinned canvas (owned + shared) with a &#96;query&#96; object — pass it directly into conversation(&#123;action: "find", mode: "column_filters", ...query&#125;) to reproduce that exact view. (2) configure-overview — personalize what renders on a deal's strategic OVERVIEW for an AOP: add/remove overview items (fields or docs), gate them by a visibleWhen condition, change render mode, reorder, or reassign owner. Use when the user says e.g. "always show a battlecard for enterprise deals", "add a Champion field", "hide Forecast". Pass configureOverview: &#123; aopId?, ops: &#91;...&#93; &#125;. For one deal use configureOverview:&#123;scope:"deal",conversationId,mode:"read"&#125;; then mode:"patch",overrideOps:&#91;add/remove/hide/show/reset/reorder/setRender&#93;. Read the returned items to verify. Shared AOP scope supports mode:"read" too. Does NOT cover mail/notification settings — those are config's apply-change action. (3) create-canvas — make a new saved view (pass title, type, and optionally viewConfig/data/homeViewOrder to pin it). (4) update-canvas — change a canvas's title/type/colour/icon/homeViewOrder, or its viewConfig (replaced in full) or data (merged). (5) delete-canvas — permanently remove a canvas you own. Canvas mutations are self-scoped to the owner; no cross-user form. Each action takes its params in a same-named object (e.g. action: "list-canvases" pairs with a listCanvases: &#123;&#125; object) — omit every params object except the one matching your chosen action.

</Accordion>

## Operations and scopes

| Action | Capability | Baseline scope |
| --- | --- | --- |
| `list-canvases` | Discover the caller's saved or pinned workspace views. | `crm:read` |
| `configure-overview` | Configure which fields and documents appear in an AOP's strategic overview. | `playbook:write` |
| `create-canvas` | Create a caller-owned saved canvas/view. | `crm:read` |
| `update-canvas` | Update a saved canvas configuration while preserving intended settings. | `crm:read` |
| `delete-canvas` | Delete the selected caller-owned saved canvas. | `crm:read` |

Path, account role, feature gates, target ownership, and billing permissions can impose additional requirements.
