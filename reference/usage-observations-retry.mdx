## Capabilities

[Usage and delivery recovery overview](/channels/usage) · [Complete capabilities](/capabilities/usage).

<Accordion title="Full tool behavior and constraints">

Retry delivery of your existing blocked shadow measurement to the usage ledger. Requires current spending permission and the original grant and shadow meter version. Reuses the immutable saved receipt; cannot change amounts, create grants, charge credits, or repeat provider work.

</Accordion>

Required baseline scope: `billing:write`. Additional role and target checks apply.

## Parameters

| Parameter | Type | Required | Details |
| --- | --- | --- | --- |
| `accountId` | string | Yes |  minLength: 1; maxLength: 256 |
| `measurementId` | string | Yes |  minLength: 1; maxLength: 256 |
| `user_request_summary` | string | Yes | One sentence, in your own words: what the user actually asked you to do in this turn. Used only for Cedar's observability — it does not change what this tool does.  |
| `is_new_request` | boolean | Yes | true on the FIRST Cedar tool call of a NEW user request; false when this call continues the same request you are already working on. Groups related calls into one activity thread.  |
