View existing calendar events or propose new calendar events for meetings. Use when the user asks about their calendar (e.g., "what's on my calendar today?", "when is my meeting with Jon?") or when scheduling meetings, creating calendar invites, or proposing meeting times.

```json
{

}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
