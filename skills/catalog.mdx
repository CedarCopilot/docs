title: "Skills"
description: "Find an operating skill and its named resources for the current Cedar connection."

Skills supply account-aware operating instructions; tools execute operations. Loading a skill does not add missing tools or bypass permissions. Use the named loader and resource exactly as listed.

| --- | --- | --- |

| [task-view-analytics](/skills/task-view-analytics) | `load-skill` | Analyze task and output activity in a view the caller can access. |
| [drafting](/skills/drafting) | `load-skill` | Prepare email, Slack and LinkedIn drafts using the rep’s writing preferences. |
| [knowledge-base](/skills/knowledge-base) | `load-skill` | Look up approved product information and collateral in connected knowledge sources. |
