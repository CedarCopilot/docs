Sales methodology frameworks — BANT, SAYA (Sell As You Are), MEDDPICC, the rep onboarding coaching-report structure, and the per-stage sales process-doc template. Load when the AOP specifies a sales methodology (SAYA, BANT, MEDDPICC, etc.), when giving methodology-grounded deal feedback or call reviews, when building a rep onboarding coaching report, or when you need the authoritative structure for a per-stage sales process doc.

## Load the module

Call `load-skill` with:

```json
{
  "name": "coaching"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
