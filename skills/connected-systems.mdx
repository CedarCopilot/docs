Guidance for interacting with a user's external systems (HubSpot, Salesforce, Attio, Notion, custom tools, etc.) from a Claude session connected to Cedar. Load when the user asks you to read from or write to any system outside Cedar itself. Tells you which systems the user has connected in Cedar and what to do if you don't already have a working tool for the one they need.

## Load the module

Call `load-skill` with:

```json
{
  "name": "connected-systems"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
