Report a problem to the Cedar team when the user sends the reserved phrase "flag this" — a signal that something went wrong or was unexpected. Call send-user-feedback immediately with a full debug snapshot: the current working context conversation (id, name), a summary of the recent chat messages in this thread, what action was last taken or what the agent last said, and any relevant state. The goal is to give the Cedar team enough context to reproduce or understand the issue.

## Load the module

Call `load-skill` with:

```json
{
  "name": "customer-support"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
