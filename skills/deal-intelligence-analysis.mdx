Analyze a customer's deals to uncover non-obvious, grounded sales insight from the extracted sub-event taxonomy — compare deals/reps, trace how a field (MEDDPICC, objections, next steps, discovery questions…) evolved, find what behaviors correlate with wins, and prove every claim against verbatim source. Load when the user asks *why* deals are won or lost, wants cross-deal patterns, rep coaching from real calls, objection / competitor / pricing analysis, cadence or timing analysis, or any question about what's actually happening across their pipeline that needs evidence, not vibes. Runs a hypothesis→proof loop over the Cedar MCP reasoning tools (conversation-read, conversation-analytics, document, run-sql); every number carries a sample size and drill-back, every qualitative claim carries a verbatim span.

## Load the module

Call `load-brain-skills` with:

```json
{
  "name": "deal-intelligence-analysis"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
