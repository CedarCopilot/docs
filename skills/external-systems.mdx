Connect to and interact with external, non-Cedar systems. Three paths: MCP-connected integrations (Notion, outreach trackers, custom tools) via call-mcp-tool; Cedar-integrated providers (Google, Salesforce, HubSpot, Slack, Stripe); and credentials the user stored themselves (Xero, Microsoft Graph, an internal API). The last two both go through get-provider-credentials, then an HTTP caller (run-code-executor in the background, native Bash in chat). Load when the user wants to read from or write to any external system.
