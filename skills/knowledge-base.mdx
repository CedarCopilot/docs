Access the user's Knowledge Base text entries, uploaded KB documents, and any connected external MCP knowledge bases (e.g. product docs, support docs). Use when you need specific reference information: links, product details, pricing, competitor info, or documentation. For creating/updating/deleting KB entries, use the cedar-configuration skill instead.

## Load the module

Call `load-skill` with:

```json
{
  "name": "knowledge-base"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
