Build and drive a Cedar TABLE — a row-addressed spreadsheet an agent fills. Load before reading or writing ANY table document, and whenever a task has N independent units of work: designing the columns and their fill instructions with the user, binding columns to live Cedar data (`conversation.stage`, `conversation.fields.&lt;key&gt;`), sourcing rows from a query or an import, and fanning out one agent per row to fill them in parallel.

## Load the module

Call `load-skill` with:

```json
{
  "name": "tables"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.
