description: "Organize work, maintain context and verify what a rep can see."
---

On an enabled account, call `load-skill` with `{"name":"task-views"}`. Use the instructions to discover a destination, inspect its schema and current revision, and read its visible rows. Place an existing task when someone owns a next step. Add a context row when the rep only needs a deal or resource for reference.

Saved placement rules shape future organization. Delivery is separately configured and can remain silent. Verify each result by reading the saved configuration or locating the row in the destination. [Task Views](/tasks/task-views)
