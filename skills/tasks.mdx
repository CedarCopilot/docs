Everything task-related: creating, updating, and canceling personal and sales-conversation tasks; surfacing and ranking follow-ups for today (use when user asks "who do I need to follow up with?"). Covers dedup, due dates, batching, and pipeline hints. The automated morning run lives in the separate `daily-agenda` skill.

## Load the module

Call `load-skill` with:

```json
{
  "name": "tasks"
}
```

Read the returned instructions in full. Account-specific playbook context is assembled at load time; this static reference does not publish it.

## Resources

This skill has no separately registered named resources. Its primary instructions contain the workflow.
